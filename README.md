# portafolio-api

[![CI](https://github.com/NestorHnr/portafolio-api/actions/workflows/ci.yml/badge.svg)](https://github.com/NestorHnr/portafolio-api/actions/workflows/ci.yml)

API REST del portafolio de Néstor Heredia (Java Developer · AI Agents).
Stack: Java 21 · Spring Boot 4.1 · Maven · PostgreSQL 17 (pgvector) · Docker Compose.

Para levantarla: copia `.env.example` a `.env`, ejecuta `docker compose up -d` y luego `./mvnw spring-boot:run`.

Diseño y arquitectura: Néstor Heredia · Implementación asistida con Claude Code
